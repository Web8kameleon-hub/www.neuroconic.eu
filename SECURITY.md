## Reporting a Vulnerability

We take security seriously at Neurosonic / ABA GmbH. If you discover a
security vulnerability, please follow these steps:

### DO NOT
- ❌ Do NOT create a public GitHub issue
- ❌ Do NOT disclose the vulnerability publicly

### DO
- ✅ Email: clisonix@pm.me (encrypted preferred)
- ✅ Include detailed description and reproduction steps
- ✅ Allow time for assessment and fix

### Response Timeline
- 24h: Acknowledgment of receipt
- 72h: Initial assessment
- 7 days: Fix or mitigation plan

### Our Commitment
- We will investigate all valid reports
- We will provide fixes in a timely manner
- We will publicly acknowledge responsible disclosures

## Security Architecture

Neurosonic is built on Zero Trust principles:

- **Zero Trust Architecture**: No entity trusted by default
- **Encryption at Rest**: All stored data encrypted
- **Encryption in Transit**: All communications encrypted
- **DDoS Protection**: Built-in flood protection
- **Audit Trail**: Immutable logs with hash chains
- **No Fake Enforcement**: CI/CD blocks simulated/fake code
- **Zero External Dependencies**: No supply chain attacks
