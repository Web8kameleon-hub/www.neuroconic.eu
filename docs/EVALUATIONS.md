# Neurosonic Evaluations

Faqe qendrore për vlerësimin teknik, produktiv dhe operacional.

## 1) Scorecard Framework

| Dimension | Weight | Key Indicators |
| --- | ---: | --- |
| Reliability | 30% | Uptime, startup success, crash-free sessions |
| Quality | 25% | Test pass rate, regressions, defect escape |
| Delivery Velocity | 15% | Cycle time, release cadence |
| User Ownership | 15% | Local save success, git export success |
| Governance & Compliance | 15% | Policy checks, audit traceability |

## 2) Rating Bands

- **90–100:** Excellent
- **80–89:** Strong
- **60–79:** Good
- **40–59:** Needs Stabilization
- **0–39:** Critical

## 3) Weekly Evaluation Template

- Scope i javës
- Çfarë u dorëzua realisht
- Metrikat e javës
- Rreziqet e hapura
- Vendimet për javën pasardhëse

## 4) Monthly Review Gate

- Krahasim me muajin e kaluar
- Trend i reliability dhe quality
- Niveli i përmbushjes së Stepstones
- Vendim: continue / stabilize / re-prioritize

## 5) Release Evaluation Checklist

- [ ] Feature tested and reproducible
- [ ] Liability boundary documented
- [ ] Changelog updated
- [ ] Tag + GitHub release published
- [ ] Post-release verification done

## 6) Suggested Cadence

- Weekly: 30–45 min team review
- Monthly: 60–90 min governance review
- Quarterly: strategic architecture and roadmap reset
