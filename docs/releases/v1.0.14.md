# Neurosonic v1.0.14

Release date: 2026-09-04

## Highlights

- Add a release-readiness command that aggregates repository guards, complete
  tests, and optional live checks without creating tags or deployments itself.
- Replace in-process benchmark and trace probes with HTTP checks against an
  explicitly supplied backend URL.
- Add guarded production autodeploy: it runs only after successful CI on `main`
  and only when the production environment enables it.
- Align Python, npm, Rust and backend API metadata to version `1.0.14`.
- Replace test doubles in UI security and shell trace tests with direct runtime
  contract checks.

## Operational note

The full live benchmark remains an operational gate. It must be run against the
target deployment before relying on latency or availability conclusions:

```bash
python scripts/release_readiness.py --run-tests --base-url https://www.neurosonic.eu
```
