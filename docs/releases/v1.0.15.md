# Release v1.0.15

Date: 2026-09-04

## Highlights

- Stabilized the Personal UI Composer for non-technical users with safer, more human-friendly chat flows.
- Hardened API protections around malformed LLM output, noisy text, and empty requests.
- Verified Cloudflare custom rule handling for `/api/*` and `/healthz` without blocking legitimate traffic.
- Aligned version metadata for package, runtime API, and release documentation to the 1.0.15 release line.

## What changed

### UI & UX

- Human-friendly UI Composer interaction for users without technical backgrounds.
- Safer widget generation with default fallback rules for empty or invalid plans.
- Reduced noisy or repetitive responses in generated panel descriptions.
- English-first user messaging for broad public usage and simplified mass-market onboarding.

### Backend & API hardening

- Added stricter validation for UI chat payloads.
- Added guardrails for malformed or repetitive LLM responses.
- Added safer default widget rendering and schema normalization.
- Preserved Zero Fake / Zero Noise behavior while keeping the UX simple and accessible.

### Cloudflare & deployment safety

- Confirmed API path rules for `/api/*` and `/healthz` with WAF skip logic in Cloudflare.
- Documented the origin timeout and 403 challenge edge cases caused by managed challenge rules.
- Kept deployment guidance focused on production-safe, non-breaking behavior.

## Edge cases covered

- Empty UI request payloads.
- Missing profile/plugin metadata.
- Repetitive or noisy LLM output.
- Invalid or partial JSON schema generation.
- 403/Challenge blocks caused by Cloudflare security rules.
- Cloudflare origin timeout situations on initial HTTPS setup.
