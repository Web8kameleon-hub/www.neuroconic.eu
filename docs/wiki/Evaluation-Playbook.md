# Evaluation Playbook

## Evaluation Dimensions

1. **Reliability**: uptime, startup success, error-rate
2. **Quality**: test pass rate, regressions, lint hygiene
3. **Velocity**: lead time, release cadence, cycle completion
4. **Ownership**: user-controlled data/export success
5. **Governance**: policy compliance and auditability

## Scoring Model

- 0–39: Critical
- 40–59: Needs Stabilization
- 60–79: Good
- 80–89: Strong
- 90–100: Excellent

## Weekly Review Template

- What changed this week?
- Which stepstone moved forward?
- What risk increased?
- What will we fix next week?

## Monthly Decision Gate

- Continue current roadmap
- Re-prioritize backlog
- Harden operations before new features
