# Operations Stepstones

Kjo faqe liston checkpoints operacionalë për ritëm të shëndetshëm delivery.

## Stepstone 1 — Stable Core

- Health endpoint green
- Startup scripts pa konflikte portesh
- Core tests kalojnë

## Stepstone 2 — Product Surface

- Dashboard dhe UI Composer aktiv
- Plugin attach/list i verifikuar
- Liability guards aktive

## Stepstone 3 — Ownership & Portability

- Git-save endpoint funksional
- Repo/path validations aktive
- Manual recovery steps të dokumentuara

## Stepstone 4 — Release Excellence

- Changelog i përditësuar
- Tag semantik i krijuar
- GitHub Release i publikuar

## Exit Criteria

Një iteracion quhet i mbyllur kur:

- ka evidencë testimi,
- ka dokumentim të përditësuar,
- dhe ka release note të qartë.
