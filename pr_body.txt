## Release: v1.0.9 - Warning Cleanup & Diagnostics Hardening

This release improves code quality and lint hygiene across core runtime and docs-facing files without changing public API contracts.

### What changed

- `neurosonic_seo.py`
	- Removed redundant UTF-8 encoding declaration
	- Sorted imports
	- Replaced naive date/time usage with timezone-aware UTC calls

- `neurosonic_lightning_bridge.py`
	- Removed deprecated typing usage in key signatures (`dict`/`list`, `X | None`)
	- Cleaned import block and removed unused imports
	- Replaced broad `except Exception` handlers with narrower exception groups in health/request code paths
	- Removed non-interpolated f-string

- `README.sq.md`
	- Fixed markdownlint issues (heading semantics, non-empty badge links, table spacing style, final quote formatting)

- `personal_node/ui_composer.html`
	- Replaced inline style with CSS class (`.actions-row`)

### Validation

- `pytest -q`: `18 passed, 1 warning`
- Diagnostics significantly reduced; one analyzer warning remains for `scripts/rolling_update_backends.ps1` and appears tool/analyzer-specific in current environment.
